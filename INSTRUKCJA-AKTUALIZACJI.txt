AKTUALIZACJA KLASY 4I — DWIE WERSJE NOTATKI JAVASCRIPT

Co dodaje ta aktualizacja?
- Zachowuje kartę „JavaScript — notatki: podstawowa i rozszerzona” w dziale Teoria programowania.
- Dodaje na stronę obie wersje notatki:
  * podstawowa — 13 stron A4, PDF i Word;
  * rozszerzona — 46 stron A4, PDF i Word.
- Udostępnia osobne przyciski pobierania oraz przełączany podgląd PDF na stronie.
- Zachowuje odnośniki do W3Schools.
- Aktualizuje Service Workera, aby obie notatki były zapisywane do pamięci offline.

Jak wgrać na istniejącą stronę GitHub Pages?
1. Pobierz i rozpakuj ZIP.
2. Otwórz folder istniejącego repozytorium Klasa 4i.
3. Skopiuj do niego CAŁĄ zawartość paczki, zachowując strukturę katalogów.
4. Potwierdź zastąpienie zmienionych plików.
5. Nie usuwaj starych folderów ani materiałów.
6. Zapisz zmiany w repozytorium (Commit changes) i poczekaj na publikację GitHub Pages.
7. Otwórz: Teoria programowania → JavaScript — notatki: podstawowa i rozszerzona.

Po publikacji odśwież stronę przez Ctrl + Shift + R. Jeżeli używasz zapisanej wersji offline, otwórz stronę raz z Internetem, aby Service Worker pobrał nowe pliki.

Ważne:
- Dotychczasowy temat „Metody obiektów: Math, Array, String” nie jest usuwany ani modyfikowany.
- Klucz postępów starego tematu `klasa4i-teoria-metody-v1` pozostaje bez zmian.
- W tej aktualizacji dochodzą dwa nowe pliki PDF i dwa nowe pliki DOCX; wcześniejsza, 46-stronicowa notatka pozostaje dostępna.
- Nie przesyłaj samego ZIP-a do repozytorium — rozpakuj go i skopiuj pliki z zachowaniem folderów.
